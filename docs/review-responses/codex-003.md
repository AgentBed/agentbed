| Lease expiry races in-flight `switch` (Critical) | **Accepted.** effects.md §3a rewritten: single-writer **decision log** (only the watchdog appends; the broker *requests*), renewable commit lease tied to commit-worker liveness, and on final expiry the watchdog **fences and terminates the commit worker (to confirmed process-group exit) before inspecting or reverting** durable state. One recovery precedence rule: a `BEGIN_COMMIT` without `COMMITTED` is always uncommitted; to resolve, acquire a fresh recovery lease under a new epoch, fence survivors, re-run mandatory invariants against the active system, then atomically choose. | Watchdog crash / OOB / epoch recovery underspecified (High) | **Accepted.** OOB now monitors a **signed watchdog heartbeat** `{host_id, tx_id, epoch, state, lease_deadline}`, so a dead watchdog in a responsive guest is detected. OOB recovery **explicitly selects the base generation** rather than trusting the current boot default, and recovery into a candidate lacking `COMMITTED` re-runs mandatory invariants first. New chaos cases added. |
| Connector must prohibit ambiguous HTTP (High) | **Accepted.** ADR §5 connector contract: **typed RPC only, never serialized HTTP** — the connector builds one fresh outbound request; all caller framing, pseudo-headers, `Host`, `Transfer-Encoding`/`Content-Length`, trailers, chunk extensions, folding, CR/LF, connection/Upgrade fields rejected; CONNECT-UDP/MASQUE/Upgrade disabled. Responses are **projected into typed allowlisted fields** (no raw headers) and scanned/redacted **before returning to the caller and before logging**. Operations whose reflection/downstream-fetch behaviour can't be bounded are rejected at compile time. |
